# AI Engineer Book

Интерактивная книга на React + Vite с MDX-парсером.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
```

## Как добавлять контент

Положите новый файл с расширением `.mdx` в `book/` или в новую подпапку вида `05-part/`. Все файлы подключаются автоматически через `import.meta.glob`, поэтому вручную регистрировать главу в коде не нужно.

Рекомендуемый формат:

```text
book/
  05-part/
    Глава 1.mdx
    Глава 2.mdx
```

Порядок определяется номером в имени файла. Файл `Введение.mdx` показывается первым, `Заключение.mdx` — последним. Заголовки `##`–`####` автоматически попадают в оглавление главы.

Изображения можно хранить в `book-assets/` и вставлять в MDX обычным Markdown-синтаксисом:

```md
![Подпись](/book-assets/example.png)
```
